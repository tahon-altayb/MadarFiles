# مدار 1.4.8 — تنفيذ أوامر Colab

أظهرت تجربة الهاتف اكتمال رفع عينة الصوت ثم فشل التنفيذ عند 27% قبل تحميل النماذج. لم تتضمن النسخة السابقة تفاصيل تكفي لإثبات السبب الفعلي في جلسة المستخدم.

يعالج هذا التحديث افتراض مسار العمل النسبي: تُنشأ النواة داخل مجلد المهمة، ويحدد عامل التهيئة المجلد الذي يحتوي ملفات المهمة صراحة قبل تشغيل المعالجة. أضيفت مرحلة تهيئة مرئية، وعنوان مناسب للتفريغ والترجمة بدل عنوان تصدير الفيديو.

قناة التنفيذ تقبل رسائل Jupyter النصية والثنائية الافتراضية، وتضيف Origin الموافق لعنوان الخادم. يمكن متابعة المهمة من تقدم REST عند انقطاع القناة. تعرض الأخطاء رموزًا محددة للقناة أو صنف خطأ Python والمرحلة الأخيرة؛ لا تُعرض أجسام أخطاء الخادم أو رموز الدخول أو traceback.

التحقق يشمل اختبارات Android لاتصال WebSocket فعلي محلي، الردود الثنائية، رفض الاتصال، أخطاء Python، الإلغاء، والمتابعة بعد الانقطاع. يتضمن التحقق اختبار Jupyter فعليًا بملفات اصطناعية عبر Contents API ومسار URL ذي بادئة، يعيد إنتاج فشل المسار القديم ثم يشغّل عامل التهيئة ويسترجع النتيجة.

هذه الاختبارات لا تستخدم حساب Google أو مقاطع المستخدم ولا تقيس جودة Whisper أو Qwen على GPU. يلزم تكرار تجربة الهاتف للتحقق من مسار جلسة Colab الفعلي وجودة التفريغ والترجمة.
