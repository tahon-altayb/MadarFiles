# مدار 1.9.5 · تصحيح اتصال المصدر وإغلاق GPU

الإصدار 40. اجتاز البناء والتحقق والتوقيع واختبارات Android في GitHub Actions.

المصدر المبني: `c1db8694549fae5a29cea77fd3d5f6b1b74e2ad1`.
تشغيل التحقق: https://github.com/tahon-altayb/MadarFiles/actions/runs/40720731385

## المشكلة المثبتة من تسجيل المستخدم

التسجيل الأول 235 ثانية والثاني 80 ثانية. كلاهما بقي عند طلب مورد L4، قبل تنزيل النموذج والفصل. رسالة WebView -6 تعني فشل اتصال صفحة المصدر، ولا تثبت وجود ترميز غير مدعوم.

## التغييرات

- جلب HTML عبر عميل HTTP الأصلي عند فشل نقل WebView، ثم تنفيذ صفحة المصدر نفسها دون جسر Android. تبقى الشهادات وقيود الشبكة العادية فعالة.
- الإبقاء على مسار الرابط ومعاملاته؛ تحويل HTTP إلى HTTPS فقط للنطاقين الرسميين streamtape.to/com. لا سماح HTTP عام.
- اكتشاف عناصر رابط الوسائط ومنها norobotlink، وفحص صيغ التشغيل stream=1 والتنزيل dl=1 عند غياب معامل التشغيل. لا تُغير بيانات token أو expires أو ip الموقّعة.
- منع نوافذ الإعلانات والتنقل الرئيسي إلى نطاق مختلف من إنهاء اكتشاف الفيديو. لا يلغي فشل صفحة لاحقة فحص رابط وسائط جارٍ. تُنقل Cookies وReferer إلى طلبات الوسائط.
- إصلاح انتظار initializer أثناء الإمساك بقفل تجمع GPU. الإغلاق الفعلي في الخلفية، مع إشعار واضح، وحظر جلسة متنافسة إلى انتهاء التنظيف حتى لا يضيع سجل ملكية المورد.
- إصلاح توقف الصوت عند نهاية دفعة جاهزة بعد تعليق مؤقت للفيديو أو إيقاف يدوي: يُستكمل الصوت الموجود في الطابور، ويُطلب احتياطي جديد بعد نفاده فعلًا أو بعد تغيير الموضع. كشف اختبار حقيقي حالة كانت تتوقف عند نحو 3.33 من 4 ثوانٍ.
- إلغاء طلب المستخدم خلال انتظار تخصيص المورد يستجيب فورًا، مع بقاء سجل العملية لإيقاف المورد بأمان في الخلفية.
- استئناف طلب GPU المملوك لنفس المشروع بعد إعادة فتح التطبيق إذا أثبتت API أنه ما زال قيد الإنشاء؛ دون حذفه أو تخصيص مورد ثانٍ. لا تُستأنف جلسة نواتها قديمة أو غير معروفة.
- عرض الوقت المنقضي الفعلي أثناء تخصيص GPU؛ هذا ليس تقديرًا لوقت انتهاء طابور Google.
- إزالة فرض L4 على فصل الموسيقى: تلقائي يتذكر آخر مورد نجح، ويبدأ T4 عند غياب سجل سابق. يتيح إعداد Colab اختيار T4/L4/A100 من الموارد المؤهلة فقط. لا يغير نموذج UVR أو جودة الفصل.
- ضغط PCM في الاتجاهين بـzlib دون فقد، مع الرجوع إلى النقل الخام إذا لم يوفّر الضغط حجمًا كافيًا. تُفحص أطوال وبصمات البيانات المنقولة ثم العينات الأصلية، ويُرفض الفك المبتور أو المتضخم. يبقى نموذج الفصل وتوقيته وعيناته دون تغيير. لا يُنسب قياس سرعة GPU إلى اختبارات CPU.
- طلبات التحكم في Colab محدودة بعشرين ثانية لكل طلب؛ نقل الصوت يحتفظ بمهلته السابقة. لا إعادة إرسال عمياء لطلب إنشاء مورد أو تنفيذ نواة.

## حدود التحقق

لا يمكن الجزم بأن مسار Streamtape الفعلي متاح من شبكة المستخدم، أو ضمان مدة توفير مورد Colab. اختبارات الاتصال تستخدم خادمًا محليًا مضبوطًا؛ لا تزعم تشغيل حلقة المستخدم أو قياس GPU فعلي بحسابه. الحزمة تُختبر على محاكي API 35، والجهاز المستهدف API 37 يحتاج تجربة فعلية.
