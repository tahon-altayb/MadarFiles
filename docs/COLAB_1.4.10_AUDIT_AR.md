# مدار 1.4.10 — مراجعة توقف معالجة Colab

## ما يثبته تسجيل الهاتف

أظهر التسجيل الأخير WS_CONNECT_TIMEOUT عند 27% بعد نحو 30 ثانية، قبل أن يظهر install أو gpu_check أو تنزيل Whisper. الفشل الحالي في إنشاء قناة WebSocket، ولا يثبت فشل النموذج أو GPU أو تكرار تعارض PyAV السابق. نجح REST الذي أنشأ الجلسة ورفع الملفات سابقًا، لكن ذلك لا يضمن نجاح قناة WebSocket.

عُثر على عيب مؤكد في سياسة مدار: مهلة فتح القناة 30 ثانية، بينما Jupyter قد ينتظر kernel_info وجاهزية النواة بمهلة افتراضية 60 ثانية. لا يثبت هذا وحده أن النواة البطيئة هي السبب الوحيد في جلسة الهاتف؛ لا تتوفر هنا حسابات Google أو سجلات خادم المستخدم. يختبر التحديث مصافحة متأخرة 32 ثانية فعلًا، ويضع مهلة 90 ثانية للمحاولة، ومحاولتين كحد أقصى قبل إرسال أي أمر.

## مسار التنفيذ بعد التصحيح

إنشاء جلسة مملوكة لمدار ← إنشاء مجلد ونواة ← فتح القناة والتحقق من مصافحة 101 ← رفع الصوت وملفات المهمة ← إرسال أمر واحد عبر القناة المفتوحة ← متابعة تقدم العامل عبر REST ← استرجاع النتيجة والتحقق منها ← إنهاء جلسة مدار.

لا يعاد إنشاء GPU بسبب فشل المصافحة. تُجدد معلومات الاتصال من API قبل محاولة فتح ثانية. لا تعاد أوامر execute بعد وضعها في طابور الإرسال، لأن نجاح socket.send لا يثبت أن الخادم نفذها أو لم ينفذها. يمكن إعادة الاتصال قبل أول إرسال فقط. إذا انقطعت القناة بعد بدء العامل تستمر متابعة الملفات، ولا يعاد تنفيذ الأمر.

| المورد غير متاح/الحصة | الأهلية لا تعني التوفر | بديل تخصيص واحد للرموز المؤقتة المعروفة، دون مضاعفة الجلسات |
| نواة ماتت أو لم يبدأ العامل | إنشاء النواة لا يثبت تنفيذ الكود | فحص حالة النواة قبل إعادة المصافحة؛ WORKER_NOT_STARTED إذا لم يظهر تقدم خلال المهلة |
| اختلاف مسار الملفات | الدليل الافتراضي ليس مضمونًا | مجلد مهمة صريح وعامل تهيئة مجرب من المجلد والأب |

| CUDA/cuBLAS/cuDNN/نوع الحساب | قد تتوفر بطاقة لكن لا تعمل المكتبات المطلوبة | فحص تحميل المكتبات ودعم float16 وعملية GPU صغيرة قبل تنزيل الأوزان؛ GPU_LIBRARIES/GPU_UNSUPPORTED |
| مساحة القرص والمكتبات الناقصة | قد يفشل التنزيل أو الاستيراد | إصدارات رقمية ومساحة متاحة في التقرير؛ DISK_FULL وMODULE_* |
| تنزيل النماذج/Hub/Xet | مهلة أو رفض أو 429 أو انقطاع | مهلة تنزيل أطول، HTTP بدل Xet، رموز MODEL_HTTP_* وMODEL_NETWORK |

| عامل توقف عن إرسال نبضاته | قد تتعطل العملية أو تُنهى | WORKER_HEARTBEAT_TIMEOUT بعد نافذة 120 ثانية دون نبضة؛ وقت محلي رتيب لا ساعة الخادم |
| Qwen/Transformers/bitsandbytes | CUDA أو نسخة غير متوافقة أو JSON ترجمة ناقص | إصدرات مثبتة، تحقق صارم من معرفات السطور، وبقاء النص الأصلي عند فشل الترجمة |
| ترجمة انقطعت بعد اكتمال التفريغ | قد تكون النتيجة الأصلية سليمة بالفعل | استرجاع النص الأصلي المتحقق منه مع تحذير صريح؛ لا تقديمه كترجمة مكتملة |
| ردود غير صالحة أو كبيرة | بيانات ناقصة أو صيغة مختلفة | حدود حجم وتحقق JSON/timing/line count؛ دعم رسائل Jupyter النصية والثنائية الافتراضية |
| الإلغاء أو خروج التطبيق أو إنهاء النظام للخدمة | قفل الهاتف ليس اختبارًا لسلامة النقل | خدمة أمامية وقفل CPU موجودان؛ إلغاء القناة سريع، وتتبع الجلسة المملوكة وإعادة تنظيفها لاحقًا؛ لا ضمان callback عند قتل النظام للعملية |
| فشل إنهاء الجلسة | حذف محلي أو توقف الواجهة لا يثبت انتهاء الحساب | تبقى جلسة مدار في السجل ويظهر CLEANUP_PENDING؛ زر إنهاء الجلسة السابقة |

## التقرير القابل للنسخ

من «اتصال Colab» ثم «حالة آخر معالجة Colab». يحفظ التقرير إصدار مدار، نوع الشبكة ووجود VPN، Android API، رموز المراحل وأوقاتها، حالة التنظيف، وإصدارات مكتبات رقمية والمساحة المتاحة حين يمكن استرجاعها. لا يحفظ رموز OAuth أو Proxy-Token، ولا روابط الجلسة أو مسارات الملفات أو الحوار أو لقطات الشاشة أو رسائل الاستثناء الخام. التقرير محلي، ولا يُرسل تلقائيًا.

## التحقق وحدوده

تشمل الاختبارات المصافحة المتأخرة، إعادة المحاولة قبل التنفيذ فقط، إلغاء المصافحة، تنفيذًا واحدًا، استرجاع REST بعد الانقطاع، الردود الثنائية، الأخطاء الخاصة، نبضات العامل، حدود المرحلة، التقرير المنقّى، واستعادة النص الأصلي. اختبار Jupyter فعلي يفتح القناة قبل PUT لملفات المهمة. اختبار Whisper فعلي يستخدم tiny على CPU للتحقق من المكتبات وخيارات التوقيت وVAD، لا لتقليص نموذج المستخدم.

لم يُنفذ large-v3 أو Qwen على GPU داخل حساب المستخدم من هذه البيئة. لا يمكن إثبات جميع حالات الشبكات أو تغييرات Colab المستقبلية، ولا اعتماد الدقة اللغوية من نجاح اختبارات الاتصال. تُستخدم تجربة الهاتف التالية للتحقق من الطرف الحقيقي، ومع الفشل يُطلب التقرير المنسوخ بدل دورة لقطات وتخمين.
