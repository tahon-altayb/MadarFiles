# مدار الملفات 1.5.1

عند رفض رفع صورة أو فيديو إلى Drive كانت نسخة 1.5.0 تخفي سبب Google الفعلي وتعرض رسالة تجمع تفعيل API والمساحة والمشاركة. أصبحت الرسالة الآن مبنية على رمز السبب، مع مرحلة الفشل وتشخيص قابل للنسخ من داخل QR. لا تُحفظ رسالة الخادم الخام أو الحساب أو التصريح أو عنوان جلسة الرفع.

إذا كان السبب `SERVICE_DISABLED` أو `accessNotConfigured` يظهر زر إعداد المشروع. يستعمل الزر مشروع الخطأ الفعلي إن أعاده Google، وإلا مشروع Firebase المضمّن. يلزم مالك المشروع تفعيل `drive.googleapis.com` مرة واحدة؛ التطبيق لا يستطيع تجاوز هذا الإعداد.

إذا اكتمل الرفع وفشلت مشاركة الرابط، يظل الملف مسجلًا وخاصًا، ويمكن إعادة مشاركة الرابط وإنشاء QR من «ملفاتي المرفوعة» دون إرسال بايتات الملف مجددًا. يمكن أيضًا إنشاء QR لأي رابط متاح موجود في السجل. الأخطاء الدائمة لا تُعاد داخل حلقة نقل الملف؛ أخطاء الخادم وحد الطلبات قبل الرفع وأثناء مشاركة الرابط لها محاولات محدودة وقابلة للإلغاء.

التحقق: اختبارات HTTP فعلية على خادم محلي، وتصنيف أخطاء Google القديمة والحديثة، ومنع تسريب الرسائل والروابط، وواجهة متصفح بأعراض شاشة الهاتف، واختبارات تخزين التشخيص على Android. التشغيل بحساب المستخدم وإعداد مشروعه يحتاج تجربة Google الفعلية؛ لا يُعد نجاح الخادم المحلي إثباتًا لتفعيل API.
