# مدار 1.9.7 · cuDNN الخاص بفصل الموسيقى

الإصدار 1.9.7 (versionCode 42) بُني ونجح التحقق من حزمة التحديث بالتوقيع الأصلي.

## دليل GPU الفعلي

نفّذ المستخدم اختبار A/B على Tesla T4 / torch 2.11.0+cu130 / CUDA 13.0. A مع cuDNN 9.27.0 وFULL أخفق في Conv_18 بنفس HEURISTIC_QUERY_FAILED. B مع cuDNN 9.13.0.50 المحمّل في عملية مستقلة وFULL نجح مع تحقق أطوال وبصمات مخرجات الصوت: 17 ثانية استغرقت 4.21 ثانية، ودفعة ثانية واحدة استغرقت 0.60 ثانية. جاهزية العامل B بلغت 2.41 ثانية مع وجود النموذج والحزم من الاختبار السابق. هذه الأرقام لا تشمل تنزيل حزمة cuDNN الخاصة ولا رفع الصوت عبر شبكة الهاتف، وليست وعدًا بزمن بدء بارد أو سرعة ملف كامل.

## التنفيذ

- يرفع التطبيق music_launch.py مع العامل. يجهز launcher cuDNN 9.13.0.50 في مجلد مدار خاص بجلسة CUDA 13، دون تبديل حزم Colab الرئيسية أو حل تبعياتها مجددًا. يتحقق من وجود المكتبة ومحرك precompiled قبل حفظ التثبيت، ويعيد استخدام المجلد في نفس المورد.
- بعد تجهيز البيئة ينفذ execve لعملية نظيفة، فيزول import torch والمكتبات المحملة في launcher. يمرر المسار الخاص وFULL قبل تشغيل العامل، ويحمل العامل cuDNN قبل torch/sherpa ويتحقق من cudnnGetVersion==91300. مسار CUDA 12 السابق لا يُغيّر إلى حزمة CUDA 13.
- لا تعلن ready حتى ينجح فصل صناعي بطول سياق النافذة (6 ثوانٍ)، مع فحص شكل المخرجات والعينات وتخصيص GPU. لا ينشر الصوت الصناعي في النتيجة ولا يغيّر توقيتها. فشل هذا الاختبار يمنع رفع ملف المستخدم.
- تبقى نفس أوزان UVR وبصمتها والنوافذ وتحويل PCM، مع جلسة وعامل ونموذج محملين لدفعات الملف والملفات التالية وفق سياسة الخمول السابقة.
- تحفظ حالة الخروج الأصلية عند السباق بدل إخفائها خلف PROCESS_EXIT، وتُصنّف رسالة فشل cuDNN المعروفة برمز MUSIC_CUDNN_CONV دون حفظ نص الخطأ الخام.

## الاختبارات والحدود

نجحت اختبارات العامل المحلية (11)، ومنها تثبيت الخاص مرة واحدة وإعادة استخدامه، تمرير البيئة إلى الابن فقط، وتنفيذ فحص الاستدلال قبل الجاهزية وكشف عدم تخصيص GPU. الاستدلال في هذه الاختبارات بديل؛ دليل CUDA الحقيقي هو تقرير المستخدم أعلاه. نجح تحقق دمج التطبيق وحزمة التحديث على محاكي Android API 35: مجموع 202 اختبارًا (8 مصدر المشغّل + 2 وكيل محلي + 8 مشاهدة متزامنة + 184 اختبارًا عامًا). نجح البناء وlint واختبارات Jupyter الفعلية وWhisper وHy-MT2 والواجهة، وتثبيت التحديث فوق 1.4.17 مع التوقيع الأصلي. هذه اختبارات دمج Android؛ دليل CUDA الحقيقي هو تقرير المستخدم، ولا يُدّعى أن مسار تثبيت المكتبة من التطبيق أو كل موارد GPU جُرّبت بحساب المستخدم قبل إصدار APK.
