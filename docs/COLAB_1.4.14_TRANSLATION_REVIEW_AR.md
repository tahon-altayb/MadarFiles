# مدار 1.4.14 — مراجعة الترجمة وحماية النص الأصلي

## ما أثبته تقرير التشغيل

اكتملت معالجة 1.4.13 على GPU باستخدام NF4، واستمر جلب النتيجة عبر REST بعد انقطاع WebSocket. اكتمال التنفيذ لا يثبت صحة الترجمة. المقارنة بين التفريغ والترجمة كشفت أخطاء معنى، وحروفًا أجنبية متبقية داخل العربية، وأخطاء تعرف على كلمات المصدر. لا يوجد دليل يثبت أن تكميم NF4 وحده سبب هذه الأخطاء.

## التغيير

- استخدام إعدادات Qwen3 الموصى بها لوضع non-thinking: sampling، وtemperature=0.7، وtop_p=0.8، وtop_k=20، وmin_p=0. بدل greedy decoding. المصدر: https://huggingface.co/Qwen/Qwen3-8B#best-practices
- ترجمة الدفعة بسياقها، ثم مراجعة ثانية مقابل المصدر نفسه لتصحيح المعنى والنفي والضمائر والتعابير والأسماء. المراجعة تستخدم النموذج نفسه؛ ليست حكمًا مستقلًا أو ضمانًا لصحة المعنى.
- لا تُحفظ المسودة في نتيجة أو checkpoint؛ الحفظ بعد قبول استجابة المراجعة فقط. أي فشل يحتفظ بالتفريغ الأصلي ويظهر تحذيرًا بدل إعلان نجاح الترجمة.
- رفض الحروف اليابانية/الصينية/الكورية المتبقية وشظايا الكلمات العربية اللاتينية في الترجمة العربية، مع احترام الكتابة التي طلبها المستخدم صراحة في قاموس الأسماء. هذا فحص حروف، وليس فحصًا آليًا لصحة المعنى.
- محاولة إصلاح محدودة، ثم تقليل حجم الدفعة عند استمرار خطأ البنية أو اللغة أو تجاوز السياق أو الذاكرة. لا توجد إعادة محاولة بلا حد.
- مرحلة `translation_review` مستقلة في الواجهة والتشخيص ومراقب المهلة: لكل توليد ومراجعة حد 240 ثانية، مع بقاء الحد الكلي للعملية. لا تُحسب المراجعة ضمن مهلة المسودة.
- الأسماء المستخرجة للمقاطع التالية يجب أن تكون موجودة في نص الدفعة. لا تُضاف الأسماء التي اقترحتها المسودة مباشرة إلى قاموس السياق.
- ربط checkpoints بإصدار سياسة الترجمة، حتى لا تُستأنف نتائج قديمة لم تمر بالمراجعة الجديدة.
- إبقاء نص ASR وتوقيته كما أخرجهما نموذج التعرف. لا تُستبدل الكلمات الملتبسة بتصحيح قصصي مخمَّن.

## التحقق وحدوده

اختبارات العقد تفحص مرور المصدر والسياق إلى المراجعة، وعدم حفظ المسودة عند فشلها، وثبات التوقيت والمصدر، وإبطال checkpoints القديمة، وحدود الاسترداد. اختبار Qwen الصغير يستخدم إعدادات التوليد الإنتاجية مع أوزان عشوائية على CPU للتحقق من توافق API فقط. اختبارات Android تفحص ظهور تشخيص رفض الترجمة والاحتفاظ بالأصل.

مسار البناء يفحص الترقية من 1.4.13 إلى 1.4.14 بالشهادة الأصلية. هذه الفحوص لا تقيس جودة Qwen3-8B على GPU ولا تثبت تحسن الترجمة اليابانية. يلزم تشغيل المقطع نفسه بالإصدار الجديد ومقارنة الناتج بالمصدر للتحقق من ذلك. المراجعة تضيف استدعاء توليد لكل دفعة وتزيد وقت المعالجة.
