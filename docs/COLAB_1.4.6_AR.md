# تجربة معالجة التفريغ والترجمة على Colab — 1.4.6

تضيف نسخة التجربة خيارًا ثالثًا لأداة التفريغ والترجمة: Colab GPU. يحتفظ التطبيق بخياري المعالجة المحلية وGemini. إعادة ترجمة النص المراجع تبقى على المحركين المدعومين سابقًا. فصل الموسيقى عبر Colab غير مفعّل بعد.

يختار المستخدم اللغة والهدف وقاموس الأسماء الاختياري، ويوافق صراحة على رفع صوت المقطع واستهلاك وحدات حساب Colab. الموافقة غير محددة افتراضيًا وتُمسح عند تبديل الخدمة. زر تجربة أول 30 ثانية يستخدم المسار نفسه. الحد التجريبي للملف الكامل 10 دقائق.

التصريح عبر شاشة Android الأصلية. يُنقل لمرة واحدة في ذاكرة العملية خلال دقيقتين، دون إدخاله في Intent أو WebView أو التقرير أو التخزين. يرسل OAuth إلى Colab API فقط، وتصريح اتصال الجلسة إلى عنوان HTTPS الموثوق الذي يعيده Colab. تمنع إعادة التوجيه. تُجدد بيانات اتصال الجلسة دوريًا.

تُطلب جلسة جديدة باسم عشوائي يخص مدار ومعرّف طلب UUID4 ثابت لمنع تكرار الإنشاء الملتبس. تُفضّل L4 ثم T4 ثم A100 ذات الذاكرة العادية حسب الأهلية، وتوجد محاولة مورد بديل واحدة بعد رفض تخصيص مكتمل. لا تُستعار جلسات المستخدم الأخرى أو تُحذف. تحفظ هوية الجلسة ومعرف العملية دون أسرار قبل المعالجة لاسترجاع الإنهاء بعد الانقطاع. فقدان رد الإنشاء يُحل بمعرف الطلب نفسه. زر إنهاء جلسة مدار السابقة يطلب التصريح ثم ينهي الجلسة المسجلة فقط.

يُرفع الصوت 16kHz mono في أجزاء 30 ثانية عبر Jupyter Contents، ويُجمع قبل التفريغ لمنع قطع السياق عند حدود النقل. يبدأ Python kernel خاص بهذه الجلسة ويشغل العامل المضمن عبر بروتوكول Jupyter WebSocket. لا يفتح العامل خادمًا عامًا. تُعرض مراحل تحميل المكتبات والنماذج والتفريغ والترجمة والاسترجاع والإنهاء. توجد حدود زمن وحجم، وإلغاء يقاطع الشبكة ثم يحاول إنهاء جلسة مدار؛ إن فشل الإنهاء تبقى هويتها والتنبيه للمراجعة. إنهاء إسناد الجلسة لا يمثل ادعاء بمحو فوري من بنية Google.

العامل يستخدم faster-whisper / Whisper large-v3 مع VAD حساس للنداءات القصيرة وتوقيت الكلمات، ثم يحرر نموذج التفريغ من GPU ويحمل Qwen3-8B بكمّية NF4 للترجمة السياقية. قاموس المستخدم وأسماء المشهد والسياق السابق واللاحق بيانات داخل طلب الترجمة. لا يُستبدل لفظ ملتبس مثل شين بالموت بقاعدة نصية عمياء. تُفحص هوية كل سطر وتطابق التوقيت وعدم غياب الترجمة. فشل الترجمة يحفظ التفريغ الأصلي مع تنبيه. لا تُعرض استجابات أو tracebacks خام.

اختبارات Python لا تحتاج شبكة وتغطي تقسيم الكلمات وحفظها وتوقيتاتها، صرامة إجابات الترجمة، والاحتفاظ بالأصل عند فشل نموذج الترجمة. اختبارات Android تغطي اختيار الموارد، حصر عناوين HTTPS، نقل التصريح لمرة واحدة، مطابقة رد التنفيذ، تطابق النص والتوقيت، تعقب الإنشاء والإنهاء، المحاولة البديلة المحدودة وحماية جلسات الآخرين والإلغاء. لا تثبت هذه الاختبارات توفر GPU أو توافق صورة Colab الحالية أو جودة المعنى؛ يلزم تشغيل حي على جهاز الحساب الموافق عليه ومراجعة المقطع نفسه.
