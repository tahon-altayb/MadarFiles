# مدار الملفات · MadarFiles 1.1

تطبيق أندرويد عربي لتحويل الصور والفيديو وPDF وتعديلها، مع معالجة محلية وقائمة أدوات دائرية.

## الجديد في 1.1

- إزالة الموسيقى داخل الجهاز باستخدام نموذج UVR: تجربة أول عشر ثوانٍ قبل معالجة الملف كاملًا، حفظ فيديو بالصوت المعالج أو M4A، تقدم وإلغاء من الإشعار. تُنسخ إطارات الفيديو الأصلية دون إعادة ترميزها.
- استخراج النص العربي والإنجليزي من الصور باستخدام Tesseract محليًا.
- استخراج النص من PDF النصي، واستخدام OCR تلقائيًا للصفحات المصوّرة. اختيار نطاق حتى 50 صفحة في العملية.
- محرر للنص المستخرج مع النسخ والحفظ كـ TXT أو DOCX حقيقي قابل لتعديل النص.
- معاينة مباشرة للصور والقص والتدوير والخلفيات؛ معاينة مصغرة لتأثير جودة JPG/WebP، مع عرض الأبعاد.
- تحريك تحديد القص وتكبيره وتصغيره بسحب الحواف والزوايا؛ لا يُعاد رسمه عند تحريكه.
- معاينة الفيديو أثناء تعديل حدّي القص وكتم الصوت، ومعاينة صفحة PDF عند تغيير رقمها.
- تشغيل النتيجة داخل التطبيق قبل الحفظ والمشاركة. تتوقف وسائط المعاينة عند إغلاقها.

## الإمكانات السابقة

تحويل الصور JPG / PNG / WebP / PDF، قص وتغيير مقاس وضغط وتدوير وإضافة خلفية وهوامش وزوايا مستديرة. تصدير الفيديو إلى MP4 بترميز H.264 أو H.265، قص المدة وتقليل الدقة ومعدل البت وكتم الصوت واستخراجه إلى M4A. تحويل PDF إلى صور وتصدير نطاق كـ PDF مصوّر. الحفظ عبر مدير الملفات والمشاركة وسجل آخر 50 نتيجة.

## حدود واضحة

- فصل الموسيقى يستهدف إبقاء الصوت البشري. لا يضمن حذف كل الموسيقى أو الاحتفاظ بكل المؤثرات؛ قد تتأثر أصوات البيئة والغناء والتفاصيل المختلطة بالموسيقى. يُفضّل اختبار العينة أولًا. لا تُقدّم هذه النسخة ضمانًا للحوار والمؤثرات كلٍ على حدة.
- تُجرى المعالجة على CPU الجوال. يزيد حجم APK بسبب تضمين النماذج، وقد يستغرق الفصل وقتًا ويستهلك البطارية. الإلغاء يُنفذ بين أجزاء المعالجة، وليس أثناء استدعاء النموذج الجاري.
- دعم OCR يتأثر بوضوح الصورة والخط والتخطيط. يجب مراجعة الأسماء والأرقام والنصوص الدينية قبل الاستخدام.
- Word يحتوي النص قابلًا للتحرير؛ لا يضمن استعادة شكل PDF الأصلي أو الجداول أو الأعمدة أو الصور. النص المصوّر يُقرأ بـ OCR. الملفات المحمية تتطلب فك حمايتها أولًا.
- معاينة ضغط الصورة مصغرة وتقريبية. معاينة الفيديو تعرض القص والصوت؛ أثر الترميز ومعدل البت يُراجع بعد التصدير.
- مخرج الفيديو العام MP4 فقط، والصوت M4A. فصل الموسيقى يحفظ الفيديو الأصلي إن كان ترميزه صالحًا داخل MP4؛ عند عدم التوافق يُحوّل المصدر إلى H.264 أولًا.
- الصور تُعالج حتى 4096 بكسل للضلع الأطول، وتحذف بيانات EXIF والموقع من النسخة. JPG يضع الأبيض خلف المناطق الشفافة.
- النتائج داخل مساحة التطبيق؛ حفظها خارج التطبيق يحميها من الحذف عند إلغاء تثبيته.
- نسخة iOS لم تُنفذ بعد. ملفات الواجهة مستقلة نسبيًا عن أندرويد لتسهيل إعادة استخدامها.

## الخصوصية والبناء

لا يطلب التطبيق إذن الإنترنت أو إذن الوصول الشامل للتخزين. تُنزّل النماذج أثناء بناء APK على GitHub وتُضمّن فيه. راجع `THIRD_PARTY_NOTICES.md` للمصادر.

البناء: JDK 17، Gradle 8.9، Android SDK 35، NDK 27.2.12479018، CMake 3.22.1. شغّل `python3 scripts/prepare_models.py` قبل البناء المحلي لتجهيز النماذج والمكتبات. تحتاج بيئة البناء إلى الاتصال، بينما التطبيق النهائي يعمل محليًا.

GitHub Actions يبني `MadarFiles-1.1.0.apk` ويشغّل اختبارات الوحدة وAndroid lint واختبارات أندرويد على محاكي API 35، ثم يثبّت Release ويلتقط واجهته. تقرير الاختبارات ولقطة الواجهة وعينة فصل اختبارية توجد في `MadarFiles-verification`.

التوقيع تطويري شخصي. المفتاح في `.signing/` محليًا، ولا يُرفع إلى Git؛ تحفظه Actions cache في مسار صريح. قبل التوزيع العام يجب إنشاء مفتاح توزيع دائم وحفظه في Secrets. إذا اختلف توقيع نسخة سابقة، لا يمكن تثبيت التحديث فوقها؛ يجب حفظ النتائج المهمة خارجيًا قبل إزالة القديمة.
