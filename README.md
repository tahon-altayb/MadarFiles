# مدار الملفات · MadarFiles

تطبيق أندرويد شخصي بواجهة عربية وقائمة أدوات دائرية مستوحاة من الفيديو المرجعي.

## الإمكانات المنفذة في المصدر

- الصور: تحويل JPG / PNG / WebP / PDF، قص بالسحب أو نسبة ثابتة، تغيير المقاس، الضغط، التدوير، وإضافة خلفية وهوامش وزوايا مستديرة.
- الفيديو: استيراد الملفات التي تدعمها برامج فك الترميز على الجهاز، تصدير MP4 بترميز H.264 أو H.265، تحديد بداية ونهاية بالثواني، تقليل الدقة ومعدل البت، كتم الصوت، واستخراج AAC داخل M4A. تظهر حالة التصدير وإلغاؤه في إشعار.
- PDF: معاينة/تحويل صفحة إلى صورة، وتصدير نطاق حتى 50 صفحة كملف PDF مصوّر. إنشاء PDF من صورة.
- اختيار الملفات من أندرويد أو مشاركة ملف إلى التطبيق، الحفظ عبر مدير الملفات، المشاركة وفتح النتائج، وسجل آخر 50 ملفًا.
- المعالجة محلية، والتطبيق لا يطلب إذن الإنترنت أو إذن الوصول الشامل للتخزين.

## حدود النسخة

- هذا **مصدر إصدار أولي** وليس APK مفحوصًا بعد. لم يُبنَ على Android SDK في الجلسة الحالية لعدم توفر الأدوات والاتصال اللازم لتنزيلها. اختبارات أندرويد أدناه معدّة للتنفيذ في GitHub، ولم يُدّع تشغيلها محليًا.
- الإخراج المرئي للفيديو MP4 فقط، والصوت M4A فقط؛ لا تصدير AVI أو MKV أو WebM في هذه النسخة. دعم الاستيراد مرتبط بالجهاز والمصدر.
- PDF الناتج عن استخراج الصفحات مصوّر؛ لا يحتفظ بالنص القابل للبحث والروابط. لا توجد ميزة PDF إلى Word أو OCR.
- حجم الفيديو بعد الضغط غير مضمون أن يكون أقل من الأصل، خصوصًا إن كان المصدر مضغوطًا أصلًا. HDR وملفات DRM وبعض الترميزات قد تفشل على أجهزة معينة.
- الصور الكبيرة تُصغّر قبل المعالجة بحيث لا يتجاوز الضلع الأطول 4096 بكسل، وتُزال بيانات EXIF والموقع من الناتج. تحويل JPG يضع الأبيض خلف الشفافية.
- خلفية الصورة إطار حولها وخلف المناطق الشفافة؛ هذه الميزة لا تعزل الأشخاص تلقائيًا.
- النتائج محفوظة في مساحة التطبيق حتى حفظ نسخة خارجية؛ حذف التطبيق يحذفها. يُرجى حفظ الملفات المهمة باستخدام زر الحفظ.
- لم تُنفذ نسخة iOS. ملفات الواجهة داخل `app/src/main/assets` مستقلة عن أندرويد لتسهيل إعادة استخدامها، بينما محركات المعالجة تحتاج تنفيذًا أصليًا على iOS لاحقًا.

## بناء APK على GitHub

1. أنشئ مستودعًا جديدًا مستقلًا باسم `MadarFiles` بحساب `tahon-altayb`، ويفضل Private. فعّل Add README عند الإنشاء.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بما فيها `.github/workflows/build.yml`؛ لا تجعل `.github` داخل مجلد إضافي.
3. يبدأ سير عمل **Build MadarFiles APK** عند الرفع إلى `main` أو `master`، ويمكن تشغيله يدويًا من Actions.
4. بعد نجاح **Build and lint APK**، يظهر ملف `MadarFiles-1.0.0-APK` في Artifacts. فك ZIP الناتج لتجد `MadarFiles-1.0.0.apk`.
5. انتظر أيضًا نجاح **Device processing tests**. وجود APK وحده لا يعني نجاح اختبارات المعالجة.

لا توجد مفاتيح API أو كلمات مرور مطلوبة. التوقيع تطويري شخصي، ويُحفظ مفتاحه في Actions cache. إذا حُذفت الذاكرة المؤقتة فقد يتغير المفتاح؛ عندها قد يلزم إلغاء تثبيت النسخة السابقة قبل التحديث. احفظ النتائج خارج التطبيق قبل إلغاء التثبيت. قبل التوزيع العام أو النشر في المتجر يجب إعداد مفتاح توقيع خاص دائم محفوظ في GitHub Secrets.

## التحقق

محليًا، نُفذت بنجاح:

- `node --check app/src/main/assets/app.js`
- `node qa/interface.test.cjs`: تدفق اختيار النوع، الجسر الأصلي، قص الفيديو وحدوده، التقدم، معالجة الفشل، سجل النتائج والمشاركة، وأسماء الملفات التي تحتوي على HTML.
- تحليل بناء Java النحوي وملفات Android XML وWorkflow YAML.

على GitHub بعد الرفع:

- `gradle testDebugUnitTest lintRelease assembleRelease`
- محاكي Android 35: فحص نتائج القص والتدوير والمقاسات والخلفيات بالبكسل، دورة صورة ← PDF ← صورة، النطاقات غير الصحيحة ومسارات الملفات، وقص الفيديو وتغيير دقته وكتمه واستخراج صوته والتحقق من المدة والمسارات.

للبناء محليًا: Java JDK 17، Gradle 8.9، Android SDK 35. شغّل `gradle assembleRelease`.

## البنية

- `MainActivity.java`: اختيار الملفات والجسر المحلي والخصوصية والحفظ والمشاركة.
- `ImageProcessor.java` / `PdfProcessor.java`: محركات الصور وPDF الأصلية.
- `VideoExportService.java`: Media3 Transformer في خدمة أمامية.
- `app/src/main/assets/`: الواجهة المشتركة، بدون مكتبات أو مصادر خارجية.
- `app/src/androidTest/`: اختبارات المعالجة على أندرويد وملف فيديو اختباري مولّد.

تبعيات المعالجة: AndroidX Core 1.15.0، Media3 1.5.1. إصدارات ثابتة لتفادي تغير واجهات البناء تلقائيًا.
